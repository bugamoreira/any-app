emergência e UTI, em português. O codebase está em `v2/` a partir da raiz

   padrões do projeto e do CLAUDE.md
3. `v2/handoff-claude-code/TAREFAS.md`  — backlog priorizado e estruturado
4. `v2/handoff-claude-code/anexos/ANALISE-PRE-LANCAMENTO.md`  — relatório

6. `v2/CLAUDE.md` (se existir) — regras do projeto, têm prioridade máxima

Regras NÃO NEGOCIÁVEIS:

- NÃO altere conteúdo clínico (doses, thresholds, fórmulas, textos de
  orientação médica) sem sinalizar explicitamente e pedir aprovação.
- NÃO adicione emojis em nenhuma UI.
- NÃO introduza dependências novas sem justificar em PR.
- Commits atômicos, um por tarefa, com mensagem no formato
  `<CATEGORIA-ID>: <descrição curta>`  (ex: `LAYOUT-03: remover hack
  translate-x do Header`).
- Sempre rode `cd v2 && npm run build` antes de abrir PR. Zero erros de TS.
- Cada PR deve referenciar os IDs das tarefas que cobre.

Modo de trabalho desejado: **um único branch `handoff/v2-pre-launch`**
com commits atômicos por tarefa. Ao final, um PR grande com changelog
detalhado. Se alguma tarefa bloquear outra (dependência), execute na
ordem certa.
